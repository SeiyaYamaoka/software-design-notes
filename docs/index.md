## このサイトの目的

このサイトは、ソフトウェア設計について広く浅く把握し、
必要になった分野を深掘りするための個人用ノートです。

AIに作成させた文章をそのまま信用するのではなく、
公式ドキュメントや書籍、実務経験をもとに内容を更新します。

## 学習方針

1. まず一言で説明できるようにする
2. 解決する問題を理解する
3. メリットとデメリットを把握する
4. 類似手法との違いを整理する
5. 実務で使ったら事例を追記する
