# AGENTS.md

## Project

This repository is a Japanese software-design knowledge site built with VitePress.

## Goals

- Learn software design broadly before studying individual topics deeply
- Explain trade-offs rather than presenting one design as universally correct
- Connect concepts to FastAPI, Next.js, React, and PostgreSQL
- Preserve practical notes learned from real development

## Commands

```bash
npm install
npm run docs:dev
npm run docs:build
npm run docs:preview
```
